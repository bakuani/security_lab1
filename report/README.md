# Сборка и проверка отчёта

Титульный лист и три основных раздела оформлены по структуре предоставленного примера.
Содержание раздела 2 генерируется из полного корневого `README.md`, включая иллюстрации.

Из корня проекта:

```sh
python scripts/build-report.py
```

Требуются Python 3 и Typst. Сторонние Python-пакеты и пакеты Typst не нужны.
Для явного указания более позднего успешного запуска:

```sh
python scripts/build-report.py --pipeline-url https://github.com/bakuani/security_lab1/actions/runs/RUN_ID
```

`report.typ` — основной исходник; `readme.typ` — генерируемый исходник раздела 2;
`evidence.json` — сведения о зафиксированном запуске; `screenshots/` — снимки реальных
страниц GitHub Actions и отчётов из артефактов. Готовый `report.pdf` создаётся локально.
