# Отчёт в Typst

Откройте `report.typ` в Typst и соберите документ самостоятельно.

- `report.typ` — титульный лист и основные разделы.
- `readme.typ` — текст README для отчёта; его можно редактировать напрямую.
- `pipeline.txt` — ссылка на успешный запуск CI.
- `screenshots/` — скриншоты SAST и SCA.

Используются шрифты Times New Roman и Courier New.
